# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please use the [GitHub private vulnerability reporting feature](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) to disclose it directly to the maintainers.  
Do **not** open a public issue for security matters.

We will review and respond to all reports as quickly as possible.

## Supported Versions

Only the current live app is supported.
